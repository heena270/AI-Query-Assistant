🤖 AI Query Assistant
📌 Overview

AI Query Assistant is a simple web application that allows users to query data using natural language. Instead of writing SQL queries, users can type simple commands like “above 40” or “show all”, and the system processes the request to display relevant results.

🚀 Features
🔍 Natural language query input
📊 Dynamic data filtering (above, below, all)
💻 Interactive UI using Streamlit
⚡ Fast and simple query processing
🧠 Beginner-friendly AI-like logic
🛠️ Tech Stack
Python
Streamlit
Basic Query Parsing Logic

▶️ How to Run

1.Clone the repository:
git clone https://github.com/your-username/AI-Query-Assistant.git
Navigate to the project folder:

cd AI-Query-Assistant
2.Install dependencies:
pip install -r requirements.txt

3.Run the app:
python -m streamlit run app.py
